## 음의 절대높이

*예시* A#4
*구성*
- 옥타브 안의 음높이를 나타내는 알파벳. C, D, ..., G, A, B 를 사용한다. 예시의 A.
- 반음 위를 나타내는 # 혹은 반음 아래를 나타내는 b. 필요할 때에만 사용한다. 예시의 #.
- 옥타브를 나타내는 숫자. 예시의 4.

## 음의 상대높이

*예시* 6b
*구성*
- 기준음을 기준으로 음의 상대높이를 나타내는 숫자. 1에서 시작하며 메이져 스케일에 대응. 예시의 6.
- 반음 위를 나타내는 # 혹은 반음 아래를 나타내는 b. 필요할 때에만 사용한다. 예시의 b.

## 음의 절대높이를 사용하는 코드

*예시* C#m/E
*구성*
- 근음을 나타내는 부분. 예시의 C#.
- 메이저 혹은 마이너 코드를 나타내는 부분. 마이너 코드일 때에만 m을 붙인다. 예시의 m.
- 그 외의 코드 특성을 나타내는 부분.
	- aug: 5번음을 반음 올린 augmented 코드
	- dim: 3번, 5번음을 반음 내린 diminished 코드
	- 7: b7번음을 추가한 7th 코드
	- maj7 : 7번음을 추가한 7th 코드
	- 7b5: 5번음을 반음 내리고 b7음을 추가한 half-diminished 코드
- 함께 연주해야 하는 근음을 나타내는 부분. 예시의 /E.

## 음의 상대높이를 사용하는 코드

*예시* ii
*구성*
- 근음과 메이저 혹은 마이너 코드를 나타내는 부분. 근음은 로마자를 사용해 표기하고, 메이저 코드와 마이너 코드는 각각 대문자와 소문자를 사용한다. 예시의 ii.
- 그 외의 코드 특성을 나타내는 부분.
	- aug: 5번음을 반음 올린 augmented 코드
	- dim: 3번, 5번음을 반음 내린 diminished 코드
	- 7: b7번음을 추가한 7th 코드
	- maj7 : 7번음을 추가한 7th 코드
	- 7b5: 5번음을 반음 내리고 b7음을 추가한 half-diminished 코드
- 참고로 ii/V는 근음이 아니라 세컨더리 도미넌트 코드를 의미함. [[Diatonic Chord]] 참고.
