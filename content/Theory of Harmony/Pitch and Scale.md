## 음에 대하여

음(音)이란 특정 주파수를 지니는 소리를 말한다. 예를 들어 A4라고 불리는 음은 440Hz 의 주파수를 가진다. 서로 다른 두 음이 조화롭게 들리는지 여부는 두 음의 주파수의 비율에 의해 결정된다. 

만약 두 음이 각각 주파수 $f_1$과 $f_2$를 가진다고 하자. 이때 두 음의 간격은 다음과 같이 정의되는 cent 라는 단위를 통해 나타낸다.

$$
\text{cent}(f_1, f_2) = 1200 \cdot log_2 (\frac{f_1}{f_2})
$$

예를 들어 A4음은 440Hz, A5음은 880Hz 를 가진다. 따라서 두 음의 간격 $\text{cent}(\text{A5}, \text{A4})$는 1200 이다.

## 음의 절대높이

악기를 조율하기 위해서는 특정 주파수를 기준으로 하여 음의 이름을 정할 필요가 있다. 이와 같이 주파수에 직접 대응되는 음 이름은 알파벳을 사용하여 표기한다. 이때 다음과 같은 규칙으로 음 이름이 정해진다.

| 주파수   | 이름         | $\text{cent}(-, \text{A4})$ | 한글명      |
| ----- | ---------- | --------------------------- | -------- |
| ...   | ...        | ...                         |          |
| 440Hz | A4         | 0                           | 라 (4옥타브) |
| -     | A#4 or Bb4 | 100                         |          |
| -     | B4         | 200                         | 시        |
| -     | C5         | 300                         | 도 (5옥타브) |
| -     | C#4 or Db4 | 400                         |          |
| -     | D5         | 500                         | 레        |
| -     | D#5 or Eb5 | 600                         |          |
| -     | E5         | 700                         | 미        |
| -     | F5         | 800                         | 파        |
| -     | F#5 or Gb5 | 900                         |          |
| -     | G5         | 1000                        | 솔        |
| -     | G#5 or Ab5 | 1100                        |          |
| 880Hz | A5         | 1200                        | 라        |
| ...   | ...        | ...                         |          |

표에서 볼 수 있듯 음이름은 '알파벳 + (# 혹은 b) + 숫자'로 구성되어 있다. 이때 알파벳은 한 옥타브에서 음의 위치를 나타내고, # 혹은 b은 반음(100 cent)위 혹은 아래 음을 의미한다. 숫자는 옥타브를 나타낸다. 일반적으로 옥타브를 나타내는 숫자를 생략하고 A 등으로 표기하는데 이는 맥락에 따라 적절하게 해석하면 된다. 때때로 이는 모든 옥타브에서의 A, 즉 ..., A3, A4, A5, ... 를 의미하기도 한다.

## 음의 상대높이

반면에 우리는 특정 음을 기준으로 하여 그 음과의 거리를 바탕으로 다른 음에 이름을 붙일 수 있다. 이때 기준이 되는 음을 키(key)라고 한다. 이와 같이 특정 음을 기준으로 음 이름을 붙일 때는 숫자를 사용한다. 아래 표는 키의 주파수가 $f_0$일 때 음 이름이 붙는 규칙을 나타낸 것이다. 

| $\text{cent}(f, f_0)$ | $f : f_0$                                        | 이름         |
| --------------------- | ------------------------------------------------ | ---------- |
| 0                     | $1 : 1$                                          | 1          |
| 100                   | $2^{1/12} : 1 = 2^{1/12} : 1$                    | #1 or b2   |
| 200                   | $2^{2/12} : 1 = 2^{1/6} : 1 \approx 9:8$         | 2          |
| 300                   | $2^{3/12} : 1 = 2^{1/4} : 1$                     | #2 or b3   |
| 400                   | $2^{4/12} : 1 = 2^{1/3} : 1 \approx 81 : 64$     | 3          |
| 500                   | $2^{5/12} : 1 \approx 4:3$                       | 4          |
| 600                   | $2^{6/12} : 1 = 2^{1/2} : 1$                     | #4 or b5   |
| 700                   | $2^{7/12} : 1 \approx 3:2$                       | 5          |
| 800                   | $2^{8/12} : 1 = 2^{2/3} : 1$                     | #5 or b6   |
| 900                   | $2^{9/12} : 1 = 2^{3/4} : 1 \approx  27:16$      | 6          |
| 1000                  | $2^{10/12} : 1 = 2^{5/6} : 1$                    | #6 or b7   |
| 1100                  | $2^{11/12} : 1 = 2^{11/12} : 1 \approx  243:128$ | 7          |
| 1200                  | $2^{12/12} : 1 = 2 : 1$                          | 8 (octive) |
| ...                   | ...                                              | ...        |

## 메이저 스케일과 마이너 스케일

스케일(scale, 조)이란 일정한 규칙으로 음을 나열한 것이다. 조의 시작음은 앞서와 같이 키라고 부른다.

메이저 스케일(major scale, 장조)은 음의 상대높이를 기준으로 1, 2, 3, 4, 5, 6, 7번 음으로 구성된다. 예를 들어 C음을 키로 하는 C 메이저 스케일은 C, D, E, F, G, A, B 로 구성된다. 장조로 구성된 음악은 일반적으로 밝은 느낌을 준다.

마이너 스케일(minor scale, 단조)은 음의 상대높이를 기준으로 1, 2, b3, 4, 5, b6, b7 으로 구성된다. 예를 들어 C음을 키로 하는 C 마이너 스케일은 C, D, Eb, F, G, Ab, Bb 으로 구성된다. 단조로 구성된 음악은 일반적으로 어두운 느낌을 준다.

단조에서 b7 대신 7을 사용하면 1, 2, b3, 4, 5, b6, 7으로 구성된 음계를 얻는데 이를 하모닉 마이너(harmonic minor)라고 부른다. 이렇게 하면 도미넌트 코드(dominant chord)인 5를 메이저 코드(major chord)로 만들 수 있다는 장점이 있다. (관련 내용은 [[Diatonic Chord]] 참고.)

메이저 스케일과 마이너 스케일이 서로 같은 경우가 있다. 예를 들어 C 메이저 스케일과 A 마이너 스케일은 둘 다 C, D, E, F, G, A, B 로 구성된다. 이와 같은 관계를 나란한 조(relative key)라고 부른다. 나란한 조를 활용하면 밝은 분위기와 어두운 분위기를 같은 곡에서 조화롭게 사용할 수 있다.

## 펜타토닉 스케일

펜타토닉이란 5개의 음으로 구성되는 스케일을 말한다. 메이져 펜타토닉 스케일은 1, 2, 3, 5, 6 음으로 구성되는 스케일로 여러 전통 음악에서 사용되어 왔다. 예를 들어 국악의 궁상각치우가 메이져 펜타토닉 스케일이다.
